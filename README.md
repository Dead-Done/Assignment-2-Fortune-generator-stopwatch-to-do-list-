# CSE 391 Assignment 2

This repository contains three standalone JavaScript assignments. GitHub Pages can serve the root landing page and each question folder as a separate page.

- `Question 1 - Fortune Generator/` — openable fortune box, Refortune button and four themes.
- `Question 2 - Stopwatch/` — Start, Stop and Reset; one real second advances the display by three seconds.
- `Question 3 - To-Do List/` — add, complete and delete tasks saved in browser localStorage.

## Run locally

Open the `index.html` file in the question folder you want to view.
